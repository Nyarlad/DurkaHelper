# Область и правила соревнования

[English](competition-rules.md) | Русский

DurkaHelper не содержит настроек конкретного турнира. Перед использованием проверьте действующие правила организаторов и официальные разъяснения; разрешение на одном мероприятии не переносится на другое.

| Область | Что подтвердить перед применением |
|---|---|
| Подготовленные материалы | Локальные скрипты, копии исходников и доступ к репозиториям |
| AI / внешние API | Различия ограничений при подготовке и во время соревнования; сканер не обращается к AI |
| Изменения сервисов | Разрешения на изменения кода, конфигурации, зависимостей, restart и migrations |
| Сетевая политика | Разрешённые порты, фильтрация, proxies и изменения контейнерной сети |
| Зарезервированная инфраструктура | Аккаунты организаторов, checkers, мониторинг и защищённые каталоги |
| Размещение | Разрешённые локальные hosts/containers и источники запросов |
| Трафик/данные | Разрешение на захват, точка наблюдения, хранение/передача и ограничения ресурсов |
| Коммуникации | Каналы команды, внешняя помощь и публикация |
| Протокол отправки | Endpoint/transport, аутентификация, формат флагов, ответы, квоты, tick/lifetime |
| Доступность | Семантика checker, SLA, сохранение старых данных и окна для патчей |

Рецепт усиления безопасности не даёт разрешения менять чужую инфраструктуру. Если настройка защищена, исправляйте в разрешённых границах приложения с сохранением функциональности; уточняйте спорные изменения до их применения.

Описанная соревновательная топология использует проводную LAN без VPN. Не предполагайте, что разрешено менять адресацию, конфигурацию коммутатора, firewall или параметры захвата. Офлайн-сканер не отправляет запросов; у health probes и инфраструктурных инструментов явно указаны другие эффекты.
