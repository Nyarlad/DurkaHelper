# Инструкция участника

[English](participant-guide.md) | Русский

Ферму устанавливать и конфиг админа заполнять не нужно. Получите у админа LAN URL/логины фермы и Packmate; авторам скриптов также нужны адрес/ключ координатора Neo.

<a id="defend-a-service"></a>
## Защитить сервис

1. Получите разрешённую локальную копию исходников сервиса Vulnbox.
2. Из каталога DurkaHelper запустите скан:

```bash
python3 durka.py scan /path/to/service --patches
```

3. Откройте связанную [инструкцию исправления](vulnerabilities/README-RU.md), проверьте применимость сигнала и изучите нужные запрос/ответ в Packmate.
4. Сохраните оригинальные файлы/native database backup, нужные сервису. Примените один небольшой фикс обычным способом доступа/деплоя команды на Vulnbox.
5. Проверьте нормальное использование и checker соревнования, включая restart/сохранность данных, где нужно. Повторите скан исходников.

Сканер делает offline source review: удалённые Vulnbox не прощупывает, их код не исполняет. Exit 1 — находки; exit 2 — некорректный/неполный вход, который нужно проверить. Чистый отчёт не заменяет доступность и ручную проверку авторизации/бизнес-логики.

<a id="inspect-traffic"></a>
## Разобрать трафик

Откройте LAN URL Packmate и войдите. Выберите свой сервис, ищите подозрительное значение/путь и изучайте запрос вместе с ответом. Для FILE попросите админа зарегистрировать сервис/шаблон до начала обработки.

Если трафика нет, проверьте timestamps потоков, IP стороны сервиса и порт/шаблон и то, импортировал ли админ закрытый файл или выбрал разрешённый LIVE-источник. Не предполагается наличие фильтра времени в UI. Один Ethernet на Mac не захватывает всю LAN автоматически. [Работа с трафиком](traffic-capture-RU.md).

<a id="write-and-distribute-scripts"></a>
## Написать и распределить скрипты

Neo — исполнитель/распределитель скриптов. Ферма собирает полученные флаги. Начните с локального теста на разрешённой цели и явно определите зависимости.

Скрипт получает IP цели первым аргументом; флаги печатает в stdout без буферизации. Диагностику отделяйте от флагов. Shebang должен указывать интерпретатор, доступный у каждого worker. Встроенный light-worker содержит shell, а не Python/Sage и произвольные пакеты.

[Настройка Neo и первое задание](neo-RU.md) описывает совместимый клиент. Сначала зарегистрируйте доверенный скрипт выключенным, затем запросите единичный прогон до периодического исполнения. `single` Neo запускает один раз на **всех настроенных командах**, поэтому сверьте scope/список с админом.

Следите за исполнением и флагами/статусом в ферме. Ферма/Neo не являются автоматическим установщиком защитных патчей.

<a id="if-access-fails"></a>
## Если нет доступа

Используйте LAN-адрес админа, а не `localhost`. Если ошибка только у вас — URL/порт, credentials и версия Neo. Если у всех — админ проверяет `python3 durka.py status` и LAN bind.

Не показывайте приватные исходники, credentials, флаги и трафик в общей трансляции. [Шпаргалка защитника](defense-cheatsheet-RU.md) · [Связи инструментов](team-setup-RU.md).
