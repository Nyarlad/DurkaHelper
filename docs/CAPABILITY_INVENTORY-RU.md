Для установки используйте [основную инструкцию](MACOS_FULL_DEPLOYMENT_AND_TESTING-RU.md), для работы — [шпаргалку администратора](TEAM_LAN_ADMIN_CHEATSHEET-RU.md).

| Инструмент | Что делает | Важное ограничение |
|---|---|---|
| Сканер DurkaHelper | Проверяет локальные исходники/конфиги; 174 правила и справочник из 294 разделов | Находки требуют ревью; нет удалённой эксплуатации или автоматических патчей |
| Defense operations | Baseline, изменения файлов, health, сравнение патчей, восстановление файлов в staging | Явная область проверки; HTTP health не заменяет checker соревнования |
| S4DFarm | Принимает флаги и отправляет их на соревнование | Поддерживается существующий адаптер ructf_http; патчи ферма не распространяет |
| Neo | Координирует командные скрипты и workers | Включайте только доверенные задачи; зависимости скрипта должны быть в worker |
| Packmate FILE | Ищет request/response в закрытом PCAP | Не непрерывный захват; опубликованный образ на Apple Silicon использует amd64 |
| Packmate LIVE | Захватывает трафик в разрешённой Linux-точке наблюдения | Подключённый к LAN Mac не видит автоматически весь трафик Vulnbox |
| Deployment helpers | Готовят закреплённые компоненты, сохраняют данные, останавливают только свой проект | Нужен Docker runtime; на Windows поддерживается core, а не этот deployment |
| Recovery helpers | Нативные dumps и восстановление в отдельный candidate | Нет слепой перезаписи production или повтора очереди |
| Офлайн-работа | Core без скачиваний; подготовленный deployment без pulls/builds | Внешний runtime нужно установить и кешировать заранее; одной копии репозитория мало |

<a id="support"></a>
## Поддержка

Core использует Python 3.10+ и только стандартную библиотеку. Тестами покрыты Windows, Linux x86-64 и hosted macOS ARM64; Docker-интеграция проверяется на Linux x86-64. Реальный Mac, Docker Desktop, видимость трафика и устройства команды требуют локальной репетиции. Логи CI находятся в GitHub Actions, а не в отчётах внутри репозитория.

Версии и идентификаторы образов сопровождаются в [toolchain.lock.json](../config/toolchain.lock.json). Проверки выполняются автоматически: оператор не заполняет SHA-формы.

Чистый scan не доказывает безопасность сервиса. Успех в лаборатории не доказывает, что сеть соревнования разрешает захват или что все участники имеют доступ к инструментам.
